# 78 by Sajainayat

A responsive, pink-themed boutique landing page for **78 by Sajainayat**.

## Files

- `index.html` — complete static website, including markup, styles, animations, product-card rendering, category filters, search, saved favourites, and Instagram enquiry links.

## Preview locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Publish with Vercel

Import this repository into Vercel as a static website. Set the Root Directory to `./`. Since the site is plain HTML/CSS/JavaScript, it does not require the Next.js framework preset or a build command.

The current product cards and imagery are editorial placeholders for the website design. Replace them with verified product names, photos, prices, and availability before presenting them as the shop's real catalogue.
